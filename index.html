Descargar reporte en Excel

Genera un archivo .xlsx con una hoja de resumen y una hoja por cada módulo (huevos, alimento, mortalidad, lotes). Funciona sin ninguna configuración.

Guardar en tu Excel de Drive

Pega el enlace de tu archivo Excel (.xlsx) que ya está guardado en Google Drive. Cada vez que guardes, se actualiza ese mismo archivo — no se crea una hoja de Google Sheets ni una copia nueva.

Configurar el motor de guardado (una sola vez)
  1. Sube o crea en Google Drive el archivo Excel (.xlsx) que quieres mantener actualizado, y copia su enlace arriba.
  2. Ve a script.google.com y crea un proyecto nuevo.
  3. Borra el contenido y pega este código:
function doPost(e) { var body = JSON.parse(e.postData.contents); var bytes = Utilities.base64Decode(body.archivoBase64); var blob = Utilities.newBlob( bytes, 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet', 'reporte.xlsx' ); var fileId = body.fileId; if (fileId) { // Sobrescribe el contenido del Excel existente, conservando el mismo enlace Drive.Files.update({}, fileId, blob); } else { fileId = DriveApp.createFile(blob).getId(); } return ContentService.createTextOutput(JSON.stringify({ ok: true, fileId: fileId })) .setMimeType(ContentService.MimeType.JSON); }
  1. En el menú lateral, junto a Servicios, pulsa el "+" y agrega el servicio avanzado Drive API.
  2. Implementar → Nueva implementación → Aplicación web. En "Ejecutar como" elige Yo, y en "Quién tiene acceso" elige Cualquier usuario.
  3. Copia la URL que termina en /exec y pégala arriba, en "URL del Web App".
  4. Importante: el archivo Excel debe estar en la misma cuenta de Drive donde implementaste el script (o compartido contigo con permiso de edición).
Los datos se guardan en este dispositivo. Usa "Generar reporte Excel" o el enlace guardado como respaldo.
